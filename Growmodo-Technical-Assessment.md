# Growmodo Technical Assessment

## Project Overview

This project involved customizing the Shopify Horizon theme to match the provided SHOP.CO Figma design. The goal was to create a modern fashion ecommerce storefront with a cleaner UI, responsive layouts, and a more premium shopping experience while preserving Shopify’s native functionality and Theme Editor compatibility.

## Development Process

The development process started by reviewing the existing Horizon theme structure and identifying which sections could be reused or redesigned. Instead of rebuilding everything from scratch, the approach focused on improving existing Shopify sections whenever possible to preserve native functionality and maintain compatibility with Shopify Online Store 2.0.

The project was developed section by section based on the Figma design reference. Each layout was first implemented for desktop and then adjusted for mobile responsiveness to ensure a consistent shopping experience across devices.

The workflow mainly involved:

- Inspecting existing Shopify Liquid sections/snippets
- Reusing Shopify-native functionality
- Refactoring layouts and spacing
- Improving responsiveness
- Adding new reusable sections where needed
- Preserving merchant customization through schema settings

## Conclusion

The final result is a modern SHOP.CO-inspired Shopify storefront built on top of the Horizon theme while preserving Shopify-native functionality and merchant customization capabilities. The project focused heavily on responsive UI refinement, reusable section architecture, and improving the overall ecommerce user experience without relying on external frontend frameworks or libraries.
